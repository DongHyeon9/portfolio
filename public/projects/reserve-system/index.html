  • 실제 데이터와 분리된 가상 팝업 · 가상 사용자로 실행 후 자동 정리

  • 정원 초과 건수는 종료 시 집계

기술 포인트

동시성

정원 10석에 80명이 동시에 몰려도 초과 예약 0건

애플리케이션 메모리 락 대신 데이터베이스의 조건부 UPDATE · 행 잠금 · 유니크 제약으로 좌석을 차감해, 서버가 몇 대로 늘어나도 정원을 넘지 않습니다.

✓ 정원 10석 · 동시 80명
→ 성공 정확히 10건, 나머지 매진 안내

신뢰성

중복 클릭 · 네트워크 재시도에도 예약은 한 번

예약 요청마다 멱등성 키를 붙여, 같은 요청이 여러 번 와도 첫 결과를 그대로 돌려줍니다. 같은 회차 중복 예약은 DB 제약으로 막습니다.

✓ 같은 요청 20회 재전송
→ 예약 1건, 좌석 1회 차감

시간

서버 시각 기준 지정 시각 오픈

예약 상태(오픈 대기 · 예약 가능 · 매진 · 마감)를 배치 작업 없이 요청마다 서버 시계로 계산합니다. 저장은 UTC, 화면은 KST로 명시해 시간대 오류를 없앴습니다.

✓ 오픈 1초 전 · 오픈 시각 · 1초 후 경계 테스트 통과

보안

서버에서 검증하는 인증

로그인은 Supabase Auth로 처리하고, 토큰은 인증 쿠키에 담아 Next.js 서버가 API를 호출합니다. Spring이 공개키로 서명을 검증하고, 관리자 권한은 서버 DB로 판정합니다.

✓ 위조 · 만료 · 권한 없는 토큰 거부 테스트 통과

배포

테스트를 통과한 코드만 자동 배포

GitHub Actions가 테스트 4단계(정책 · 웹 · API · E2E)를 통과한 main 커밋만 Google Cloud Run(API)과 Vercel(웹)에 배포합니다. 클라우드 키 파일 없이 인증하고, 롤백 · 암호화 백업도 자동화했습니다.

✓ push → 테스트 → 배포 → 상태 확인까지 자동

품질

개인정보를 남기지 않는 운영

관리자 화면의 연락처는 마스킹하고, 로그에는 개인정보를 남기지 않고 요청 ID로 추적하며, 관리자 행동은 감사 로그로 기록합니다.

✓ 로그 개인정보 미기록 자동 검사

기술 스택

서비스 웹 · 운영 대시보드

기술 상세
Next.js
서버 컴포넌트가 매 요청 최신 잔여석을 렌더링, 브라우저는 Spring API와 인증 헤더를 직접 다루지 않음, 서비스 웹과 운영 대시보드(/admin)를 한 앱에서 경로 · 권한으로 분리
React
useActionState로 서버 액션 결과(오류 · 입력값) 수신, 예약 실패 시 입력값 유지
Server Actions
별도 API Route 없이 폼 제출을 서버에서 처리, 서버가 생성해 폼에 담은 멱등성 키를 API 헤더로 전달
TypeScript
API 응답 · 오류 코드를 타입으로 고정, CI typecheck 단계에서 배포 전 타입 오류 차단

백엔드 서버

기술 상세
Spring Boot
트랜잭션 · 보안 · 검증 · 헬스체크 표준 제공, “예약해도 되는가”를 최종 판정하는 신뢰 경계
Java
LTS 버전 사용
Spring Security (JWT)
OAuth2 Resource Server로 토큰 검증만 수행, Supabase 공개키(JWKS)로 서명 확인해 서명용 비밀 미공유
JdbcClient
조건부 UPDATE · FOR SHARE/UPDATE · ON CONFLICT를 SQL 그대로 표현, 동시성 제어에서 JPA의 간접 단계 회피
Flyway
버전별 SQL 파일로 스키마 관리, 기동 시 자동 적용해 로컬 · CI · 운영 DB 스키마 일치

데이터 · 인증

기술 상세
Supabase PostgreSQL
관리형 표준 PostgreSQL, 행 잠금 · CHECK · 부분 유니크 인덱스로 정원 보장, Spring이 JDBC로 직접 연결
Supabase Auth
회원가입 · 비밀번호 저장 · 소셜 로그인 직접 구현 생략, 비대칭키(ES256) 서명 JWT를 Spring이 공개키로 검증

인프라 · 배포

기술 상세
Docker · Compose
멀티 스테이지 빌드로 JRE와 JAR만 담은 이미지, non-root 실행, 로컬에서는 Compose로 DB + API 동시 기동
GitHub Actions
테스트 게이트와 배포를 한 곳에서 관리, 테스트를 통과한 main 커밋만 배포, OIDC로 키 파일 없이 인증
Google Cloud Run
Spring 컨테이너 그대로 실행, 요청이 없으면 0대로 축소, 리비전 단위 즉시 롤백
Vercel
Next.js 웹 호스팅(CDN · HTTPS 기본), Git 자동 배포를 끄고 Actions가 빌드한 결과물만 배포

테스트 · 품질

기술 상세
JUnit 5 · Testcontainers
실제 PostgreSQL 컨테이너로 잠금 · 부분 인덱스 · ON CONFLICT 동작 검증
Vitest
시간대(KST) 변환 경계, 오류 코드 → 메시지 등 웹 로직 단위 테스트
